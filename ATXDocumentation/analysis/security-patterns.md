# Security Patterns

> See also: [Architecture Patterns](../architecture/patterns.md) | [Components](../architecture/components.md)

## 1. Bedrock Guardrails for AI Safety
- **Guardrail**: `strava-ai-boost-content-guardrail` with PROMPT_ATTACK filter at HIGH input strength
- **Selective application**: Guardrail applied only to user-provided title/description via `apply_guardrail()` API, not to the full prompt (avoids rate limiting on 230K+ char prompts)
- **Fail-open**: On guardrail API error, content is allowed through to maintain availability
- **Blocked content**: Returns safe fallback content with `guardrail_blocked: True` flag

## 2. Secrets Manager for Credential Storage
- **4 secrets**: Strava OAuth tokens, Strava app config, Campus Coach credentials, Intervals.icu API key
- **No hardcoded credentials**: All sensitive values retrieved at runtime from Secrets Manager
- **Scoped access**: Each Lambda role has access only to the secrets it needs
- **Token refresh**: OAuth tokens automatically refreshed and updated in Secrets Manager

## 3. IAM Least Privilege
- **Separate roles**: `WebhookLambdaRole`, `ContentLambdaRole`, `StravaLambdaRole`, `StepFunctionsRole` with distinct permissions
- **Resource-scoped ARNs**: DynamoDB permissions scoped to specific table ARNs (including index ARNs), Lambda invoke scoped to `StravaAIBoost-*` prefix
- **Bedrock permissions**: Scoped to specific foundation model ARNs and inference profiles
- **AgentCore permissions**: Scoped to `runtime/*` in the current account and region
- **Secrets Manager**: Read/write permissions granted per-secret, not wildcard

## 4. DynamoDB Encryption
- **Encryption at rest**: `TableEncryption.AWS_MANAGED` on all 3 tables
- **Point-in-time recovery**: Enabled on all tables
- **SQS encryption**: `QueueEncryption.KMS_MANAGED` on both processing queue and DLQ

## 5. HTTPS-Only API Endpoints
- **API Gateway**: Regional REST APIs with HTTPS by default (API Gateway always uses HTTPS)
- **External API calls**: All Strava and Intervals.icu API calls use HTTPS
- **AgentCore**: AgentCore runtime communication via HTTPS

## 6. API Key Authentication
- **Local interface API**: All endpoints require `x-api-key` header
- **Usage plan**: Rate limiting (100 req/s, 200 burst, 10K/day quota) prevents abuse
- **Key management**: API key created via CDK, key ID available in CloudFormation outputs
- **Webhook API exception**: Strava webhook endpoints are intentionally public (Strava requires unauthenticated endpoints)

## 7. Webhook HMAC Signature Verification
- **HMAC-SHA1**: `verify_webhook_signature()` validates `X-Hub-Signature` header using `webhook_secret` from Secrets Manager
- **Timing-safe comparison**: Uses `hmac.compare_digest()` to prevent timing attacks
- **Development fallback**: If no secret configured, allows requests through with warning (for initial setup)

## 8. User Isolation by Strava Athlete ID
- **User scoping**: `user_id` (Strava athlete ID) used as partition key in `user_config_table`
- **OAuth token validation**: `activity_fetcher.py` validates that the stored `user_id` matches the requested user
- **Webhook filtering**: Each webhook contains `owner_id` which is used to look up user-specific configuration

## 9. Frontend Security Patterns
- **Zero AWS SDK**: Frontend communicates exclusively via API Gateway REST endpoints — no AWS credentials exposed to browser
- **CORS restriction**: API Gateway CORS configured for `localhost:3000` and `localhost:5173` only
- **ErrorBoundary**: React error boundary prevents unrecoverable errors from crashing the entire application
- **No PII in frontend**: Frontend displays activity metadata only; no direct access to Secrets Manager or DynamoDB

## 10. Pre-commit Security Hooks
- **detect-secrets**: Scans for accidentally committed secrets using baseline file
- **detect-private-key**: Prevents committing private keys
- **check-added-large-files**: Prevents large binary files (>500KB)
- **nbstripout**: Strips Jupyter notebook outputs to prevent leaking account IDs, ARNs, PII
- **shellcheck**: Lints shell scripts for security issues

## 11. Content Safety
- **Signature marking**: All AI-generated content includes `@Generated by Strava AI Boost` signature
- **Content length enforcement**: `enforce_preferences()` limits description length based on user preferences
- **Emoji limiting**: `_limit_emojis()` enforces maximum emoji count based on user settings
- **Title length**: Enforced at 50 characters maximum
